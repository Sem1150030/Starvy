# Starvy 🌟

Starvy is an AI-powered learning platform built with Laravel. 
It helps teachers create and manage learning materials while giving 
students personalized, intelligent study content.

## Features
- 🤖 AI-generated learning materials and quizzes
- 👩‍🏫 Separate dashboards for teachers and students
- 📚 Course and lesson management
- 🔐 Authentication and role-based access
- 📊 Progress tracking

## Tech Stack
- Laravel (PHP) + Livewire
- Flux UI
- MySQL / PostgreSQL
- Open AI API
- AI-based search with Melisearch
